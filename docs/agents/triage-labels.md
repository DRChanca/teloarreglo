# Etiquetas

## Roles de triaje

| Rol y etiqueta | Significado |
| --- | --- |
| `needs-triage` | Pendiente de evaluación. |
| `needs-info` | Espera información del informante. |
| `ready-for-agent` | Trabajo definido y listo para un agente. |
| `ready-for-human` | Requiere intervención humana. |
| `wontfix` | No se realizará. |

Cuando una skill indique un rol, aplicar la etiqueta correspondiente de esta tabla.

## Clasificación adicional

| Etiqueta | Significado |
| --- | --- |
| `bug` | Error o comportamiento incorrecto. |
| `feature` | Funcionalidad nueva o ampliación. |
| `ui` | Interfaz y experiencia de usuario. |

Estas etiquetas pueden combinarse entre sí y con un rol de triaje.

Los mapas y tickets de Wayfinder llevan únicamente etiquetas `wayfinder:*`,
no etiquetas de triaje ni las clasificaciones adicionales.
